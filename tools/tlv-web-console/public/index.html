Standalone tool · TLV v1.2

Packet reader & builder

Inspect a captured packet or build one by hand. Nothing here changes the fleet, advances sequences or sends reports.

Local only · no sending

Keys are used only by this local console and are never saved by this tool. Decoding alone does not authenticate a packet.

One complete 40–64 byte packet, including the 8-byte tag. Whitespace and 0xNN byte lists are supported.

Header flags
Optional TLVs · 0–24 bytes

Complete type / length / value bytes, in wire order. Leave blank for a header-only packet. Example: 06 01 02 is reset diagnostic 2.

Known types: 04 firmware (u16), 06 reset (u8), 10 uptime (u32), 13 activity (u8), 20 ACK sequence (u16), F1 profile (u8). Multi-byte values are little-endian. Unknown types are preserved.

No key creates a diagnostic zero tag, not a packet ready for ingestion. Selecting Home does not silently alter the independently editable flags.
